# Engine 22 Micro Dual W2/W3 Transition Fibs v1

During a canonical W2 -> W3 handoff, the dashboard must preserve both sides of the transition while W3 is still DEVELOPING.

Published contract:

```
engine22WaveStrategy.microW2W3TransitionFibs
```

When available it contains:

- W2 DOWN retracement ladder from locked W1 high
- locked/confirmed W2 low
- provisional W3 UP extension ladder using locked W1 length projected from W2 low
- touched/current next W3 levels
- canonical count/version/revision provenance

Display headline:

```
W2 DOWN + W3 UP — transition confirming
```

The dual map remains visible while canonical W3 lifecycle is DEVELOPING. It collapses once W3 leaves the launch-developing phase.

This is display/intelligence only. It creates no permission, sizing, management, execution, or journal mutation.
