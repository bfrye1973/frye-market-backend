# Engine 18B — First Controlled Real Ironbeam ES Recording (PR #303)

**Status:** SOURCE CODE PREPARED, SYNTHETIC TESTED; **NOT DEPLOYED, NOT RUN AGAINST REAL IRONBEAM**. Activation and paid infrastructure require separate Engine 18 Manager approval. No chart/Engine 11/Engine 22/production monitor/trading modification.

## Implementation — existing approved Gate 1 foundation reused

- `engine18IronbeamLiveRecorderSource.js`: independent **read-only** Ironbeam v2 `/v2/auth` → `/v2/stream/create` → WebSocket OPEN → `/v2/market/{quotes,depths,trades}/subscribe/{streamId}?symbols=XCME:ES.Z26`. No trading/order/account APIs. Exact source raw text and binary are stamped **before** classification, then buffered/fsycned with durable `localSeq`, `runId`, host receipt and original vendor packet unchanged. The existing raw classifier labels depth/quote/trade, unknown/malformed/binary without inferring snapshot/delta or synthesizing market data.
- Sanitized durable CONNECTED, RECONNECT, DISCONNECTED, WS_ERROR, SUBSCRIPTION_ACK, FEED_GAP. All events bind to their own generation/stream ID. Silent feed watchdog forces a bounded supervised reconnect; source/recorder interruptions generate private reason-code alerts. Parent dashboard/market monitor is not used, edited or blocked.
- `gate1RawRecorder.js`: default synthetic-only provider remains; `IRONBEAM_V2` is permitted **only with explicit `allowLiveProvider:true` supplied from the separately gated private worker**. Preserves original high-resolution monotonic and observed host wall receipts. No other recorder rewrite.
- `engine18ControlledLiveWorker.js`: composes the **approved** bounded recorder, existing R2/S3 encrypted archive coordinator and closed-hour scheduler, existing Chrony sampler, health policy and independent live read-only source. An operator must explicitly supply protected credentials, manager-trial acceptance, independent inventory pin, exact private disk, CME calendar acceptance and a 1–30 minute supervised session. Source is stopped on failure, disk backpressure or clock-quality loss.
- `engine18ControlledLiveEntrypoint.js`: private process entrypoint; will exit without connecting unless all environment prerequisites pass. SIGTERM/SIGINT drains and stops safely; private summary includes only counts, gaps, disk free/bytes and backup failures.
- `engine18ControlledTrialVerifier.js`: **post-trial read-only** end-to-end validation of local immutable gzip/manifest/high-watermark against an independently pinned sequence and a separate, empty encrypted S3 restore. Compares deterministic SHA-256 replay and publishes only counts of depth/quote/trade/unknown/malformed/binary/GAP, never raw prices or secrets.
- `engine18LiveIronbeamSource.test.js`: synthetic fake Ironbeam v2 auth/subscription, exact raw depth/quote/trade/unknown/binary, original generation, source-error/reconnect, stalled-feed alert, fail-closed recorder, provider authorization and full encrypted mock backup restore.
- UTC and Arizona GitHub Actions rerun all previously approved Gate 1–5 regression tests; no live network or paid endpoint.
